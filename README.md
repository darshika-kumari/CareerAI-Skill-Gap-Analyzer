# CareerAI — AI Career Guidance & Skill-Gap Analysis

CareerAI is an AI-powered career guidance system that analyzes a user's resume, identifies existing skills and skill gaps, and generates a personalized career learning roadmap.

## Features

- Resume-based profile analysis
- Skill extraction
- Skill-gap detection
- Career-specific skill matching
- Personalized learning roadmap
- AI-generated career guidance
- Semantic search using embeddings
- FAISS vector search
- RAG-based career knowledge retrieval
- LLM-powered recommendations
- Streamlit web application

## Technology Stack

- Python
- NLP
- Sentence Transformers
- FAISS
- RAG
- Large Language Models (LLMs)
- Hugging Face Transformers
- Streamlit

## Workflow

Resume → Profile Analysis → Skill Analysis → Career Matching → Skill-Gap Detection → Personalized Roadmap

## Project Structure

- `app.py` — Streamlit application
- `CareerAI_Skill_Gap_Analyzer_GitHub` — development notebook
- `knowledge_base` files — career knowledge and vector index
- `sample_resume.txt` — sample input resume

## Key Idea

CareerAI does not rely only on a fixed degree-to-career mapping. It considers the user's education, skills, projects, experience, interests, and target career to provide personalized guidance.

## Future Improvements

- More career profiles
- Job-description matching

- Improved resume parsing

## Disclaimer

CareerAI provides AI-generated educational and career guidance. Its recommendations are not guaranteed outcomes and should be reviewed by the user.
